# 数据库表结构设计

引擎：SQLite（sql.js，纯 JS，无需编译），文件位于 `server/data/leads.sqlite`。建表语句以代码为准：`server/src/db.js`。
时间字段统一为**毫秒时间戳（INTEGER）**，展示时按 Asia/Shanghai 时区格式化。

## ER 关系

```
users 1 ──< leads (owner_id 当前归属人, last_owner_id 上一任, created_by 录入人)
users 1 ──< claims >── 1 leads        每次认领一行（认领历史）
users 1 ──< followups >── 1 leads     跟进记录（claim_id 关联当次认领）
leads 1 ──< lead_logs                 操作日志（只增不改不删）
industries 1 ──< leads
options（stage / intent / source）    下拉字典，leads 中按值存储
settings                              系统参数 key-value
```

|---|---|---|

| role | TEXT | `sales` 普通销售 / `director` 销售总监 / `admin` 超级管理员 |
| phone | TEXT | |
| active | INTEGER | 1 正常 / 0 停用 |
| token_version | INTEGER | 改密/重置/停用/改角色时 +1，使旧登录令牌失效 |
| created_at / updated_at | INTEGER | |

## 2. industries 行业标签

## 5. leads 线索（公海原始台账，永不删除）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER PK | |
| company_name | TEXT NOT NULL | 公司全称（查重依据） |
| contact_name | TEXT NOT NULL | 对接人姓名 |
| contact_dept / contact_title | TEXT | 部门 / 岗位 |
| contact_phone / contact_wechat | TEXT | 联系方式 |
| address | TEXT | 办公地址 |
| industry_id | INTEGER FK | 行业 |
| source / intent_level / stage | TEXT | 来源 / 意向等级 / 跟进阶段（存选项值） |
| remark | TEXT | 备注 |
| **status** | TEXT | `pool` 公海待认领 / `owned` 已认领 |
| **owner_id** | INTEGER FK | 当前认领人；CHECK：pool 必为空、owned 必非空 |
| claimed_at | INTEGER | 本次认领时间 |
| last_effective_at | INTEGER | 上次有效更新时间 |
| **expire_at** | INTEGER | 到期回流时间 = last_effective_at + 回流周期 |
| claim_count | INTEGER | 累计被认领次数 |
| last_owner_id | INTEGER FK | 上一任认领人（“曾被 XX 认领过”） |
| last_released_at / last_release_type | INTEGER / TEXT | 最近一次回流时间 / 方式（release / auto_recycle / force_recycle） |
| created_by / created_at / updated_at | | |

索引：status、owner_id、expire_at、industry_id、company_name。

## 9. 数据库层硬约束（触发器）

```sql
lead_logs  : BEFORE UPDATE / DELETE → RAISE(ABORT)
followups  : BEFORE UPDATE / DELETE → RAISE(ABORT)
leads      : BEFORE DELETE          → RAISE(ABORT)
claims     : BEFORE DELETE          → RAISE(ABORT)
```

## 10. 迁移到 MySQL / PostgreSQL（数据量大或多实例部署时）

- 字段类型：INTEGER 时间戳 → BIGINT；TEXT → VARCHAR/TEXT；
- 触发器改写为对应方言（或改为只授予应用账号 INSERT/SELECT 权限）；
- 认领原子性沿用 `UPDATE ... WHERE id=? AND status='pool'` 并检查影响行数，多实例下同样安全；
- 自动回流定时任务改为单实例执行（或加分布式锁）。
