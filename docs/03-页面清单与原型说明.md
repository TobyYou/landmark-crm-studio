# 页面清单与原型说明

一套前端（`web/`）同时服务手机 H5 和电脑管理端：屏宽 < 960px 为手机布局（顶部标题栏 + 底部 Tab），≥ 960px 为管理端布局（左侧导航）。路由为 hash 路由。

## 导航

| 角色 | 底部 Tab（手机） | 侧边栏额外入口（电脑） |
|---|---|---|
| 普通销售 | 公海 · 我的线索 · 新增 · 我的 | — |
| 销售总监 | 公海 · 我的线索 · 看板 · 台账 · 我的 | 新增线索、批量导入 |
| 超级管理员 | 同总监 | 新增线索、批量导入、系统设置 |

## 页面

### P1 登录 `#/login`
账号、密码、登录按钮；失败提示；“账号由管理员分配”。

### P2 公海线索 `#/pool`（全部角色）
- 快捷筛选：全部 / 新线索 / 回流线索
- 筛选栏（横向滚动）：关键词（公司/对接人/地址）、行业、意向等级、跟进阶段
- 线索卡片：公司名、对接人·岗位、电话（销售看到 `138****5678`）、行业/意向/阶段标签、“曾被 XX 认领 · 超时自动回流”标记、**认领**按钮
- 认领 → 底部弹层二次确认（提示 30 天规则）→ 成功后跳转详情；被抢先认领提示“手慢了”并刷新
- “＋新增线索”

### P3 我的线索 `#/mine`（全部角色，个人池）
- 快捷筛选：全部 / 即将回流（≤7 天）/ 3 天内回流 / 按最近更新排序
- 同 P2 的筛选栏
- 卡片右上角显示剩余天数；≤ 预警天数整卡橙色高亮，≤1 天红色左边框
- 空状态引导“去公海”

### P4 线索详情 `#/lead/:id`
1. 头部：公司名、状态标签“已认领｜认领人｜认领时间”、行业/意向/阶段；**回流倒计时条**（蓝/橙/红）；公海线索显示“曾被 XX 认领过（累计 N 次）”
2. 公海线索：大按钮“认领到我的个人池”（销售提示“认领后可查看完整联系方式”）
3. 客户信息：只读视图 / 编辑模式（顶部语音录入面板 + 表单，AI 填入的字段橙色高亮）
4. 新增跟进（仅归属人）：语音录入面板、跟进内容、更新阶段、下次跟进时间、提交；离线时暂存
5. 跟进记录时间线（历史认领人的记录标“历史归档”）
6. 认领历史时间线（认领→退回/回流/回收，原因）
7. 操作日志（折叠，展示字段级修改：旧值 → 新值）
8. 底部悬浮操作：归属人“退回公海”（必填原因）；总监查看他人线索时“强制回收至公海”
- 销售访问他人私池线索：显示“该线索已被其他销售认领，无权查看”

### P5 新增线索 `#/new`
语音录入面板 → 表单（必填：公司全称、对接人）→ 失焦自动查重提示 →“录入后直接认领”开关（销售默认开）→ 提交。

### P6 总监看板 `#/dashboard`（总监/管理员）
Tab：
- **总览**：5 个 KPI（公海存量、私池跟进中、N 天内将回流、本周新增、已成交）；本周流转；各销售明细表（可点“查看线索”跳台账）；行业分布堆叠条（公海/私池）
- **到期预警**：即将回流线索卡片（持有人、上次更新、剩余天数）+ 强制回收
- **流转台账**：认领/退回/超时回流/强制回收/录入/导入 流水表，按动作筛选
- **导出报表**：公海存量、私池线索、即将回流、已回流、成交、全部台账、销售统计

### P7 全员线索台账 `#/ledger`（总监/管理员）
快捷筛选：全部 / 公海待认领 / 已认领 / 即将回流；筛选栏多一个“销售”下拉；卡片显示“已认领｜认领人｜认领日期”。

### P8 批量导入 `#/import`（总监/管理员）
步骤说明 → 下载模板 → 选择 CSV（自动识别 UTF-8/GBK）→ 显示行数 → 开始导入 → 结果：成功/重复跳过/失败（附行号与原因）。

### P9 系统设置 `#/admin`（超级管理员）
Tab：账号管理（新增、改角色、停用/启用、重置密码）· 行业与选项（行业标签、跟进阶段[可勾选“计为成交”]、意向等级、线索来源：增/改名/停用/删除）· 回流与权限（回流周期、预警天数、个人池上限、三个权限开关、立即执行回流扫描）· 系统日志。

### P10 我的 `#/me`
姓名/角色；规则提醒（当前回流周期与预警天数、AI 引擎）；离线待同步数量与“立即同步”；管理入口；修改密码；退出登录。

## 通用交互
- 底部弹层确认框（手机）/ 居中对话框（电脑）；破坏性操作红色按钮
- 轻提示 toast
- 离线横幅：“当前离线：显示的是缓存数据，N 条跟进待同步”
