# 后端接口清单

- 前缀：`/api`；数据格式 JSON（导入接口另支持 `text/csv`）
- 认证：除登录外，请求头 `Authorization: Bearer <token>`
- 错误：HTTP 状态码 + `{ "error": "中文提示" }`；401 未登录/失效，403 无权限，404 不存在，409 冲突（已被认领、重复公司等），429 登录失败过多
- 列表统一返回 `{ total, page, size, items }`，参数 `page`（默认 1）、`size`（默认 20，最大 200）
- 实现：`server/src/app.js`（路由）、`server/src/leads.js`（业务 + 权限）、`server/src/reports.js`（看板/导入导出）

## 认证

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | /auth/login | 公开 | `{username, password}` → `{token, user}` |
| GET | /auth/me | 登录 | 当前用户 |
| POST | /auth/password | 登录 | `{old_password, new_password}` → 新 token（旧 token 失效） |

## 基础数据

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | /meta | 登录 | 启用的行业、阶段、意向、来源；回流周期、预警天数；总监/管理员额外返回销售名单 |

## 线索

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | /leads/pool | 登录 | 公海可认领列表。筛选：`industry_id, intent_level, stage, source, q, returned(0新/1回流)`。销售看到的电话/微信脱敏 |
| GET | /leads/mine | 登录 | 我的个人池。筛选同上 + `expire=warn` 或 `expire=N`（N 天内到期），`sort=recent` |
| GET | /leads/ledger | 总监/管理员 | 公海原始台账（含已认领）。额外：`status=pool/owned, owner_id, sort=expire` |
| POST | /leads/check-duplicate | 登录 | `{company_name}` → `{duplicate, status, mine, id?}`（他人私池不返回 id） |
| POST | /leads | 登录（销售受开关控制） | 新增线索进公海；`claim: true` 同时认领。同名公司 409 |
| GET | /leads/:id | 公海线索/本人线索/总监 | 详情 + `followups` + `claim_history` + `logs`（按权限裁剪）；他人私池 403 |
| PUT | /leads/:id | 归属人 | 修改字段；有实际变化才算有效更新并重置倒计时 → `{changed, lead}` |
| POST | /leads/:id/claim | 登录 | 认领（原子，并发只有一人成功，其余 409） |
| POST | /leads/:id/release | 归属人 | `{note}` 必填，退回公海 |
| POST | /leads/:id/recycle | 总监/管理员 | `{note?}` 强制回收任意销售线索 |
| POST | /leads/:id/followups | 归属人 | `{content, follow_at?, next_follow_at?, stage?}`，新增跟进（有效更新） |
| GET | /leads/import/template | 总监/管理员 | 下载 CSV 导入模板 |
| POST | /leads/import | 总监/管理员 | body 为 CSV 文本（或 `{csv}`）→ `{created, skipped[], errors[]}` |

## AI 语音识别

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | /ai/extract | 登录 | `{text, lead_id?}` → `{engine: "claude"/"rules", fields, followup: {content, next_follow_at}, missing[], message, warning?}`。只返回建议，不写库 |

## 总监看板 & 导出

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | /dashboard/summary | 总监/管理员 | KPI、行业分布、各销售统计、本周流转 |
| GET | /dashboard/warnings | 总监/管理员 | 即将回流清单（`expire` 可传天数） |
| GET | /dashboard/flows | 总监/管理员 | 流转台账，`action, user_id, lead_id` 筛选 |
| GET | /export/leads?scope= | 总监/管理员 | CSV。scope：`all, pool, owned, expiring, recycled, won`。写导出日志 |
| GET | /export/sales-stats | 总监/管理员 | 销售统计 CSV |

## 超级管理员 `/admin`

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /admin/users | 账号列表（含持有线索数） |
| POST | /admin/users | `{username, name, role, phone?, password}` |
| PUT | /admin/users/:id | `{name?, role?, phone?, active?}`；停用时自动回收其全部线索 → `{recycled}` |
| POST | /admin/users/:id/reset-password | `{password}` |
| POST | /admin/industries | `{name}` |
| PUT | /admin/industries/:id | `{name?, sort?, active?}` |
| DELETE | /admin/industries/:id | 已被使用则改为停用 |
| GET | /admin/options | 全部下拉选项 |
| POST | /admin/options | `{type: stage/intent/source, value, is_won?}` |
| PUT | /admin/options/:id | `{value?, sort?, is_won?, active?}`；改名同步到线索 |
| DELETE | /admin/options/:id | 已被使用则改为停用 |
| GET | /admin/settings | 系统参数 |
| PUT | /admin/settings | `{recycle_days?, warn_days?, sales_max_leads?, pool_mask_phone?, inherit_history?, sales_can_create?}`；改周期会重算到期时间 |
| POST | /admin/recycle/run | 立即执行一次自动回流扫描 → `{recycled}` |
| GET | /admin/logs?size= | 最近系统日志 |
