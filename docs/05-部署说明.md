# 部署说明

## 一、组成

```
地标公司内部销售管理系统/
├── server/          后端（Node.js + Express + SQLite），同时托管前端静态页
│   ├── server.js    入口：启动服务、自动回流定时任务、每日备份
│   ├── src/         业务代码
│   ├── test/        自动化测试（npm test）
│   ├── scripts/seed-demo.js  演示数据
│   └── data/        运行后生成：数据库、备份、密钥（务必备份，勿提交 Git）
├── web/             H5 + 管理端前端（无需构建，Vue 3）
├── miniprogram/     微信小程序壳（web-view 承载 H5）
└── docs/            PRD、数据库、页面、接口、部署文档
```

## 二、本地试用（5 分钟）

要求：Node.js 18 及以上（`node -v` 查看）。

```bash
cd server
npm install
npm run seed:demo     # 可选：生成演示账号与 44 条演示线索
npm start
```

浏览器打开 http://localhost:3000 。演示账号（仅 seed:demo 生成，密码均为 `demo1234`）：

| 账号 | 角色 |
|---|---|
| admin | 超级管理员 |
| director | 销售总监（周总监） |
| sales1 ~ sales7 | 普通销售 |

手机试用：电脑和手机连同一 Wi-Fi，手机浏览器访问 `http://电脑局域网IP:3000`（语音识别需 HTTPS，局域网下请用“输入法语音输入”）。

运行测试：`npm test`（覆盖并发认领、权限隔离、脱敏、30 天回流、历史保留、日志不可删、导入、停用回收等）。

## 三、正式部署（云服务器）

### 1. 准备
- 一台云服务器（1 核 2G 足够几十人使用），安装 Node.js 18+；
- 一个已备案域名（微信小程序和语音识别都要求 HTTPS），例如 `leads.你的域名.com`；
- 申请 SSL 证书（云厂商免费证书即可）。

### 2. 部署代码

```bash
# 上传整个项目目录到服务器，例如 /opt/dibiao-leads
cd /opt/dibiao-leads/server
npm install --omit=dev
cp .env.example .env      # 按需修改端口、初始密码、AI 密钥
npm start                 # 先前台试跑，确认无误后 Ctrl+C
```

**正式环境不要执行 `npm run seed:demo`。** 首次启动会自动创建超级管理员 `admin`，初始密码写在 `server/data/INITIAL_ADMIN_PASSWORD.txt`（或使用 `.env` 中的 `ADMIN_INITIAL_PASSWORD`）。登录后立即修改密码并删除该文件，然后在“系统设置 → 账号管理”中创建总监和销售账号。

### 3. 常驻运行（二选一）

**PM2：**
```bash
npm install -g pm2
pm2 start server.js --name dibiao-leads
pm2 save && pm2 startup
```

**systemd：** `/etc/systemd/system/dibiao-leads.service`
```ini
[Unit]
Description=Dibiao Leads
After=network.target

[Service]
WorkingDirectory=/opt/dibiao-leads/server
ExecStart=/usr/bin/node server.js
Restart=always
User=www-data
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```
```bash
systemctl daemon-reload && systemctl enable --now dibiao-leads
```

> 本系统使用单文件 SQLite，**只能运行一个进程**（不要用 PM2 cluster 模式开多个实例）。

### 4. Nginx 反向代理 + HTTPS

```nginx
server {
  listen 443 ssl http2;
  server_name leads.你的域名.com;
  ssl_certificate     /etc/nginx/cert/leads.pem;
  ssl_certificate_key /etc/nginx/cert/leads.key;
  client_max_body_size 12m;
  location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
server { listen 80; server_name leads.你的域名.com; return 301 https://$host$request_uri; }
```

### 5. 备份
- 系统每天自动备份到 `server/data/backups/`，保留 30 份；
- 建议再用云厂商快照或定时任务把 `server/data/` 同步到对象存储（异地备份）；
- 恢复：停服务 → 用备份文件覆盖 `data/leads.sqlite` → 启动。

## 四、微信小程序

当前提供的是 **web-view 壳小程序**：小程序里直接打开 H5，所有功能一套代码，后续改功能只需更新服务器。

1. 用**企业主体**注册小程序（个人主体不支持 web-view 业务域名）；
2. 小程序后台 → 开发管理 → 开发设置：
   - “业务域名”添加 `leads.你的域名.com`（按提示把校验文件放到 `web/` 目录下即可被访问）；
   - “服务器域名”无需配置（请求都在 H5 内发出）；
3. 修改 `miniprogram/app.js` 中的 `h5Url`、`project.config.json` 中的 `appid`；
4. 用微信开发者工具导入 `miniprogram/` 目录 → 预览 → 上传 → 提交审核（类目选“工具 > 办公”或企业内部使用）。

> 微信内置浏览器不支持网页语音识别接口，小程序/微信里点 🎤 会提示使用**输入法的语音输入**（微信键盘、讯飞、搜狗等都自带），转成文字后同样可以“AI 识别填充”。如需真正的“按住说话”，可后续接入腾讯云/讯飞语音识别：前端录音上传，后端转文字后复用现有 `/api/ai/extract`。

H5 也可以直接以链接/二维码形式发给销售，在手机浏览器中“添加到主屏幕”，体验接近 App。

## 五、AI 语音识别配置（可选）

- 不配置：使用内置规则识别（手机号、微信、公司名、对接人、部门、岗位、地址、行业、意向、阶段、来源、相对日期），完全离线可用；
- 配置 Claude：在 `.env` 填 `ANTHROPIC_API_KEY`，识别更准确、能理解口语化描述，并自动概括跟进内容；调用失败时自动降级为规则识别，不影响使用；
- 服务器需能访问 Anthropic API；若所在网络无法直连，可通过合规的 API 网关并设置 `ANTHROPIC_BASE_URL`；
- 识别结果只作为“建议填充”，必须由销售确认保存，不会自动写库。

## 六、常用运维

| 场景 | 操作 |
|---|---|
| 修改回流周期 / 预警天数 | 超级管理员 → 系统设置 → 回流与权限（立即生效，自动重算到期时间） |
| 销售离职 | 系统设置 → 账号管理 → 停用（其名下线索自动回收公海，账号立即无法登录） |
| 忘记密码 | 超级管理员“重置密码”；超级管理员自己忘记：在服务器上停服务，用备份恢复或联系技术人员直接重置 |
| 手动触发回流 | 系统设置 → 回流与权限 → 立即执行一次回流扫描 |
| 查看运行日志 | `pm2 logs dibiao-leads` 或 `journalctl -u dibiao-leads -f` |

## 七、后续扩展建议

- 成交单管理、广告排期、业绩统计：新增表关联 `leads.id`，看板增加模块；
- 人数/数据量明显增长或需要多实例：迁移到 MySQL/PostgreSQL（见《数据库设计》第 10 节）；
- 企业微信/钉钉登录、到期前消息推送（可复用“即将回流”查询）。
